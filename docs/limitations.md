# Limitations

- Stable mode currently supports only name plates.
- Experimental mode can fail for complex shapes or invalid CadQuery operations.
- The sandbox is not production-grade security.
- STL validation checks geometry quality, but it does not prove printability.
- There is no slicer integration and no G-code generation.
- There is no automatic printer control.
- The app does not include authentication, a database, cloud deployment, fine-tuning, or LoRA.
- Real prints should always be reviewed manually in a slicer before printing.
